**标语**：想让本地仓库里的文件不被 Git 跟踪，但又不想修改 `.gitignore` 文件，该怎么办呢？

其实，你可以用 Git 的“假装忽略”功能。具体步骤是：

1. 把你不想让 Git 跟踪的文件先用命令 `git update-index --assume-unchanged <文件路径>` 标记为“假装没变”。
2. 这样 Git 就不会管这些文件的改动了，也不会把它们提交到远程仓库。
